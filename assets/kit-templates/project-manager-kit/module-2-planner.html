Using Copilot in Planner

Turn a scope document into a working Planner board — with Copilot drafting the plan and the PM keeping judgment in the loop.

Where we are in the story: {{PERSONA_FIRST}} just got the green light on {{PROJECT_NAME}} and has a scope document, but no plan yet. Time to turn that into a working Planner board.

What you'll learn

  • Generate a first-draft plan in Planner from a project description using Copilot
  • Review and adjust a Copilot-drafted plan before treating it as real
  • Use Copilot to summarize plan status on demand, scoped to a timeframe
  • Draft a recurring meeting agenda directly from live plan data

Lesson

Step 1: Draft the Plan

Copilot can read a project description and propose a starting set of tasks, grouped into buckets — Sales workstream, Ops workstream, Support workstream — in seconds instead of an afternoon of blank-board setup.

In Planner: Paste the project scope description into Copilot's plan-generation prompt and let it propose buckets and tasks.

Step 2: The PM Reviews and Adjusts

Copilot's plan is a starting point, not the final word. {{PERSONA_FIRST}} reviews the draft, reassigns a few tasks, and adjusts dates — this is still a PM's plan, just faster to get to a working draft.

In Planner: Walk every auto-assigned owner and due date before publishing the plan to the team.

Step 3: Summarize on Demand

Once the plan is running, Copilot can summarize it — "what's off track this week" — without {{PERSONA_FIRST}} opening every task to check manually.

In Planner: Ask a scoped question like "what's off track this week," not an open-ended "summarize the plan."

Step 4: Draft the Weekly Sync Agenda

For a recurring task like a weekly sync, Copilot can draft the agenda directly from what's overdue or newly at-risk in the plan — prep goes from twenty minutes to two.

In Planner: Prompt Copilot for a sync agenda pulling current overdue/at-risk items, then review before sending.

The Loop

Draft the plan fast, keep the PM's judgment in the loop, and let Copilot handle the summarizing and prep work around it.

Job Aid — Quick Reference

A one-page checklist for using Copilot in Planner.

Before You Start

  • Have a project scope or description ready to paste in
  • Know your workstreams/buckets going in, even roughly

Core Steps

  • Paste your project description and generate a first-draft plan
  • Review every auto-assigned owner and due date
  • Reorganize buckets/tasks to match how your team actually works
  • Use the summarize feature for a weekly "what's off track" check
  • Prompt Copilot to draft your recurring meeting agenda

Common Pitfalls

  • Publishing Copilot's first draft without a PM review pass
  • Asking for a summary without specifying a timeframe
  • Letting the agenda draft replace judgment about what needs discussion

Where to Go for Help

  • Microsoft Learn documentation for Copilot in Planner
  • This kit's Prompt Library

Knowledge Check

1. What should a PM always do before treating Copilot's first draft plan as final?

Copilot's draft is a starting point — a PM review pass is what makes it trustworthy.

2. What happens if you ask Copilot to "summarize the plan" without specifying a timeframe?

Vague prompts get vague summaries — scope the ask to a timeframe like "this week."

3. What's the biggest risk of skipping a PM review pass on Copilot's draft plan?

Copilot drafts fast, but an unreviewed draft can put wrong owners or dates in front of the whole team.
