A personal agent that manages {{PERSONA_FIRST}}'s day around {{PROJECT_NAME}} — not the project itself.

Where we are in the story: Before {{PERSONA_FIRST}} even opens email, there's a way to start the day already knowing what matters on {{PROJECT_NAME}}. Time to set that up.

Lesson

Personal, Not Project-Wide

Unlike {{AGENT_NAME}}, which the whole project team uses, a personal agent is {{PERSONA_FIRST}}'s own — scoped across everything {{PERSONA_FIRST}} owns, not just one project. It manages {{PERSONA_FIRST}}'s day, not the project itself.

Step 1: Morning Brief

Set it up to generate a morning brief — today's meetings, flagged emails, and {{PROJECT_NAME}} tasks due today, in one short summary instead of five places to check.

In Copilot: Configure the morning brief, and scope it to the project(s) that matter most right now — not everything at once.

Step 2: Meeting Prep

Point it at a meeting on the calendar, and it pulls related emails and files so {{PERSONA_FIRST}} walks in briefed, not scrambling in the five minutes before.

In Copilot: Select an upcoming meeting and let the agent surface related content ahead of time.

Step 3: Inbox Triage

The agent flags anything time-sensitive tied to {{PROJECT_NAME}} so it doesn't get lost in a full inbox.

In Copilot: Turn on triage flagging for messages tied to your priority project(s).

Manage the Day, Not Just the Project

The personal agent's job is managing {{PERSONA_FIRST}}'s day around the project — so the hours go to the work, not to catching up on what's happening.

Job Aid — Quick Reference

A one-page checklist for setting up your personal agent.

Before You Start

  • Confirm your org has personal agent / Copilot features enabled
  • Know which project(s) or priorities you want it scoped around

Core Steps

  • Set up the morning brief — meetings, flagged emails, tasks due today
  • Scope it to the project(s) that matter most right now
  • Enable meeting prep for related emails/files ahead of events
  • Turn on inbox triage flagging for time-sensitive messages
  • Revisit the scope periodically as priorities shift

Common Pitfalls

  • Leaving it unscoped, so the brief is too broad to act on
  • Relying on it for meeting prep without a final gut-check on high-stakes meetings
  • Treating triage flags as a replacement for reading your inbox

Where to Go for Help

  • Microsoft Learn documentation for Copilot personal agent features
  • This kit's Prompt Library

Knowledge Check

1. How is a personal agent different from {{AGENT_NAME}}?

{{AGENT_NAME}} is project-wide and team-facing; the personal agent is scoped to one person's day.

2. What's the risk of leaving a personal agent unscoped?

An unscoped agent surfaces everything, which defeats the purpose of a quick, actionable brief.

3. Should a meeting-prep brief replace your own prep for a high-stakes meeting?

The brief is a filter and starting point, not a substitute for judgment on meetings that matter most.
